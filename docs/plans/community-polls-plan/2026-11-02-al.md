# 2 November 2026: upstream voting research for Keyring

Parent: [../community-polls-plan.md](../community-polls-plan.md).

Read from upstream source and docs on 2 November, at
[VTI 3139e00e](https://github.com/OpenVTC/verifiable-trust-infrastructure/tree/3139e00ec202351dc253d89b5b4f9885d7ae071e)
and [vta-browser-plugin f89796b1](https://github.com/OpenVTC/vta-browser-plugin/commit/f89796b1).
Nothing was run, and no request was sent to any community.

## Findings

1. **Upstream has a complete voting system.** `vti-voting`, `vti-voting-service`, and the
   `vtc/elections/*` and `voting/*` tasks all exist. Upstream's guide says it runs end to end in
   tests but hasn't run on deployed infrastructure. An upstream maintainer has since offered First
   VTC for testing, so that line may be out of date.
2. **A voter needs VTA 0.69 or newer.** Files under `vta/pcs/voter` and `vta/pcs/vote`: 0 at tag
   `vta-service-v0.67.0`, 13 at `vta-service-v0.69.0`. So any agent on 0.67 can't vote today.
3. **VTC 0.17.0 lacks the newest voting work.** The guided poll builder (#2364), portal voting
   (#2367), the trusted ballot box list (#2370) and the voter tasks in JSON form (#2371) came after
   `vtc-service-v0.17.0` and are in `v0.17.1`.
4. **`voting` is an optional VTC build feature, off by default** (`vtc-service/Cargo.toml`). An
   Elections page in the console doesn't prove a VTC serves voting.
5. **A community needs a trusted ballot box in its host configuration**
   (`[[voting.trusted_ballot_boxes]]`), and the ballot box has to allow that community.
6. **The browser plugin shows the working client.** Its commits give the real order of tasks and
   rules worth keeping: a random pause of up to 20 seconds, a receipt check, a stored "you voted"
   with no choice, and asking before it reaches a new ballot box address.
7. **PCS isn't a secrecy level.** Blind tickets and one-time keys apply at `open`, `sealed` and
   `tallied-encrypted`. The levels decide who can read ballots.
8. **The member's agent sees the choice,** because `vta/pcs/vote/0.2` takes the ballot in its payload.
   It's the member's own agent, but if a provider hosts that agent, the provider is part of that
   trust. The app must not imply otherwise.
9. **Upstream calls the ballot cryptography unaudited:** "fine for polls and surveys; have it reviewed
   before a binding election" (`docs/07-voting/README.md`).

## Not checked

- Whether hosted VTC builds include the `voting` feature.
- Whether the app's community session can carry the signed reads.
- Which version First VTC runs today.

## Position it replaces

None. This is the first look at voting for Keyring.
