## 7. Lessons recorded for the next phase

- Pushes to a PR branch whose Test build is running cancel that build (`test-builds.yml`'s concurrency group): batch pushes between builds, and make the merge-grade build on the final head with nothing pushed during it.
- `git cherry-pick --abort` on a two-commit sequence rewinds both, including one already pushed; rebuild from the remote rather than force-push.
- Several `gh run watch` loops at their default interval exhaust the shared GitHub API budget (HTTP 403 at 22:10Z on 2026-11-21); one watcher at `--interval 180`, or none.
- A pull_request `branches:` filter names the PR's base, so PRs stacked on another fold branch need `fold/**` in the filters; `workflow_dispatch` works only for a workflow that exists on the default branch (404 otherwise).
- In the run-level log some steps render as "UNKNOWN STEP", so a grep for a step name there can be vacuous on a failing step; read the job-scoped log and check the denominator first.
